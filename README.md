# mystock - A股收盘价预测系统

基于 PyTorch + Baostock + Tkinter 的 A 股个股收盘价预测分析工具。

## 功能特点

- **钉钉式主界面**：左侧深色可视化导航栏（图标 + 文字菜单），点击切换右侧内容区
- **股票预测模块**：原 A 股预测功能挂在「工作台 → 股票预测」菜单下
- **可扩展菜单**：内置「数据看板 / 消息 / 通讯录 / 设置」占位模块，便于后续扩展
- **数据获取**：通过 Baostock 获取 A 股历史行情数据，支持多种复权方式和频率
- **模型选择**：支持 LSTM、GRU、Transformer 三种模型架构
- **可调参数**：所有关键参数均可在界面中调整
- **实时进度**：训练过程实时显示损失变化和进度条
- **图表展示**：Matplotlib 绘制预测值与实际值对比图
- **模型持久化**：模型可保存和加载，下次直接调用

## 可调参数

### 数据参数
- 股票代码（如 sh.600036, sz.000001）
- 起始/结束日期
- 复权方式（不复权/前复权/后复权）
- 数据频率（日K/周K/月K/分钟线）
- 特征列（逗号分隔，如 open,high,low,close,volume,amount,turn）
- 目标列（默认 close）
- 序列长度（时间窗口大小）
- 训练集比例

### 模型参数
- 模型类型：LSTM / GRU / Transformer
- 隐藏层大小
- 网络层数
- Dropout
- 双向（LSTM/GRU）
- Transformer 头数
- 前馈维度

### 训练参数
- 训练轮数
- 批次大小
- 学习率
- 优化器：Adam / SGD / AdamW
- 损失函数：MSE / MAE / Huber
- 早停耐心值

## Tushare Token 配置

「板块热度」与「热门股票」模块使用 tushare 数据源，需配置 token：

1. 在 [tushare.pro](https://tushare.pro/) 注册并获取 token
2. 在项目根目录创建文件 `tushare_token.txt`，把 token 写入第一行
   （该文件已被 `.gitignore` 排除，**不会被提交到 git**）
3. 或设置环境变量 `TUSHARE_TOKEN`
4. 重启程序，进入「股票 → 板块热度 / 热门股票」点击「加载」即可

tushare 接口权限说明：
- ✅ `pro.daily`：按交易日拉全市场日线行情
- ✅ `pro.stock_basic`：股票基本信息（含 industry 字段）
- ❌ `pro.top_list`（龙虎榜）、`pro.index_classify`（指数分类）：需更高积分权限

## ST股票表现模块

位于「工作台 → 股票 → ST股票表现」子菜单下。

### 功能
- 扫描最近 N 个月（默认 10，可手动调整）内摘帽的 ST 股
- 计算摘帽前 N 天（默认 30，可手动调整）、摘帽后 N 天（默认 30，可手动调整）的股价涨跌幅
- 同时输出市盈率、市净率、收盘价

### 结果列
| 列名 | 说明 |
|---|---|
| 股票名称 | 来自 baostock 股票基本信息 |
| 代码 | baostock 格式，如 sh.600000 |
| 开始ST日期 | 该股首次进入 ST 状态的日期 |
| 结束ST日期 | 摘帽日（isST 由 1→0 的首个交易日） |
| 摘帽前涨幅 | 摘帽前 N 天的累计涨跌幅（%） |
| 摘帽后涨幅 | 摘帽后 N 天的累计涨跌幅（%） |
| 市盈率 | 摘帽日 peTTM |
| 市净率 | 摘帽日 pbMRQ |
| 收盘价 | 摘帽日收盘价（前复权） |

### 使用
1. 在参数栏输入「最近月数 / 摘帽前天数 / 摘帽后天数」
2. 点击「开始扫描」，进度日志实时显示进度
3. 扫描结果在下方表格展示（黄色 = 摘帽后上涨，红色 = 下跌）
4. **筛选**：在「筛选（代码/名称）」输入框中输入股票代码（如 sh.600000）、6 位纯数字（如 600000）或股票名称关键词，回车或点「筛选」即可过滤；点「重置」显示全部
5. **排序**：点击任意列头排序，同一列再次点击切换升/降序；数值列默认降序，文本/日期列默认升序
6. 点击「导出 CSV」保存当前筛选后的结果

### 数据来源
与「股票预测」模块相同：baostock，使用 `query_history_k_data_plus` 接口拉取含 `isST` 字段的日 K 线，扫描 isST 由 1→0 的转折点识别摘帽日。
